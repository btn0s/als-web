# Mantle, roll, ragdoll and get up

`Character`'s local input adapter maps jump to ALS jump/mantle probing, Shift sprint/roll policy, and ragdoll/get-up binding. Code-driven players use `player.command.jumpSequence++` for a jump edge and `player.ragdoll()` for the ragdoll edge; `player.respawn(position)` recreates the capsule and clears actions. [Command](../../../src/app/AlsPlayer.ts), [input bridge](../../../src/als/AlsCharacter.hooks.ts), [action tests](../../../src/als/AlsCharacter_Actions.test.ts).

Mantle and roll use authored clips, root motion and notify gates. The local `Character` creates the Rapier mantle adapter and montage bridges; invoke actions through its input route instead of setting `locomotionAction` directly. [Character mount](../../../src/app/Character.tsx), [mantle settings](../../../src/als/Settings/AlsMantlingSettings.ts), [rolling implementation](../../../src/als/AlsCharacter_Actions.ts). `ragdollRef` exposes `StartRagdolling()` and `StopRagdolling()` for a game action policy; get-up is selected by the stop lifecycle. [Ragdoll handle](../../../src/engine/rapierAlsRagdoll.ts), [ragdoll hook](../../../src/app/useAlsRagdoll.ts). Remote action events are cosmetic; see [remote](remote.md).
