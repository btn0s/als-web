# Performance knobs

Start with `Character snapshotRateHz={20}` for network recording; this rate limits packets, not pose evaluation. [Recorder](../../../src/als/AlsCharacterRecorder.ts), [ghost test scene](../../../src/app/AlsGhostDemo.tsx). For distant remotes, set `<AlsRemoteActor footIk={false} ... />` to remove terrain queries while retaining the graph. [Remote actor](../../../src/app/AlsRemoteActor.tsx).

`AlsRemoteActor` has no camera, local input, movement sweeps or audio, but each remote still owns a skinned mesh and evaluator. Set `animationLod` from your camera or significance system to reduce graph evaluations. For example, `<AlsRemoteActor animationLod={() => ({ distance: camera.position.distanceTo(actorPosition), visible: inView, focused: selected })} ... />`. The callback runs at animation priority after snapshot playback, so it can read the latest actor position. The thresholds are 12/20/34 m for intervals 1/2/3/4, or 8 when hidden. Use `minInterval` for coarse devices and `maxInterval` to keep visible casualties responsive. The graph holds its last pose between evaluations and consumes the full elapsed time at the next evaluation; action montage and root motion states run every frame. Snapshot, collision, and received action callbacks always run every frame. [Remote actor](../../../src/app/AlsRemoteActor.tsx), [frame monitor](../../../src/app/FramePerformanceMonitor.tsx).
