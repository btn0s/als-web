# Performance knobs

Start with `Character snapshotRateHz={20}` for network recording; this rate limits packets, not pose evaluation. [Recorder](../../../src/als/AlsCharacterRecorder.ts), [ghost test scene](../../../src/app/AlsGhostDemo.tsx). For distant remotes, set `<AlsRemoteActor footIk={false} ... />` to remove terrain queries while retaining the graph. [Remote actor](../../../src/app/AlsRemoteActor.tsx).

`AlsRemoteActor` has no camera, local input, movement sweeps or audio, but each remote still owns a skinned mesh and evaluator. Set `animationLod` from all active cameras (including scoped views), conservatively including visible shadows. For example, `<AlsRemoteActor animationLod={() => ({ visible: inView, shadow: shadowInView })} ... />`. The callback runs at animation priority after snapshot playback, so it can read the latest actor position. Visible bodies and shadows always evaluate every frame. A first-person game passes `{ visible: false, shadow: true }` while the camera hides the body. Only an actor with neither a visible body nor visible shadow suspends evaluation; its first visible frame evaluates immediately and consumes elapsed time. Audible graph clocks remain current while hidden. Locomotion actions always run at full rate. Snapshot, collision, and received action callbacks always run every frame. [Remote actor](../../../src/app/AlsRemoteActor.tsx), [frame monitor](../../../src/app/FramePerformanceMonitor.tsx).

`AlsRemoteActor` evaluates through a shared pool of up to two module workers. Actors remain on one worker so state machines, montage clocks, inertialization and foot-lock history are retained. Each worker receives the skeleton hierarchy and typed clip channels once per asset bank; meshes, materials and textures stay on the renderer. Frame controls and commands are FIFO, and completed poses use transferable, recycled ArrayBuffers. The main thread publishes the latest completed pose while the next frame evaluates. There is no main-thread graph fallback. Worker poses stay warm offscreen so a sudden camera turn can publish a current pose immediately; `animationLod` gates main-thread skeleton publication.

World collision stays with the consumer: workers return foot-trace and ground-prediction requests, and the main thread sends their results into the following evaluation. The main thread also retains rigid-body ragdoll authority and applies its physics override after worker pose publication. Ragdoll handoff reads the latest published pose; snapshots cross back into the worker for the authored get-up blend. Pool workers terminate when their last actor unmounts. Transferable buffers require no COOP/COEP headers. `Character` retains the standalone locally controlled character pipeline; remote, replay and first-person shadow actors all use the worker path through `AlsRemoteActor`.
